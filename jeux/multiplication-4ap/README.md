# رحلة الأبطال في عالم الضرب — المستوى الرابع ابتدائي

لعبة تفاعلية باللغة العربية لتعلّم جداول الضرب من 0 إلى 10، مخصصة لتلاميذ مدرسة ابن الهيثم.

## التشغيل
افتح ملف `index.html` في المتصفح. اللعبة عبارة عن ملف مستقل، دون تثبيت حزم أو أوامر بناء.

## النشر على Vercel
1. اختر **Add New → Project**.
2. استورد المستودع `mkassou3030-bit/exercices` من GitHub.
3. في **Root Directory** اختر `jeux/multiplication-4ap`.
4. في **Framework Preset** اختر **Other**.
5. اترك **Build Command** فارغاً إذا أمكن، واضغط **Deploy**.

## خصائص اللعبة
- جداول الضرب من 0 إلى 10، والعمليات الرياضية من اليسار إلى اليمين (مثل `2x1=2`).
- تمارين اختيار من متعدد، وصواب أو خطأ، وإكمال الناتج، والوصل.
- تحديات ترفيهية بالقطار والكنز والمجموعات.
- تصحيح فوري للمحاولات، وتكييف حجم الخط، وحفظ النتائج محلياً.
